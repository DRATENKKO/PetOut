# Tech stack

| Área | Elección actual | Motivo |
|---|---|---|
| App | Flutter / Dart | Multiplataforma móvil, buen look nativo |
| Estado | flutter_bloc / Cubits | Separación limpia y testeable |
| Persistencia | shared_preferences + storage local | Suficiente para versión local simple |
| Mapas | flutter_map + OpenStreetMap | Sin dependencia pesada de Google Maps |
| Ubicación | geolocator | Tracking y lugares cercanos |
| Media | image_picker | Galería de momentos |
| Notificaciones | flutter_local_notifications + timezone | Recordatorios locales |
| Charts | fl_chart | Estadísticas visuales simples |
